# Parakeet MFMA Team - Official Branding Packs

## Baseline

The complete evergreen blue-and-yellow identity is in **[baseline/](baseline/README.md)**. The bird has a white circular badge background, and the full logo is transparent outside the artwork.

Use the pack's SVG/PDF masters, transparent PNGs and ready-to-use social graphics. Start with [the preview](baseline/preview.png) and [usage guide](baseline/brand-guide.pdf).

A ZIP download is available at `output/parakeet-branding-packs/parakeet-baseline-pack.zip`.

The root-level Parakeet PNG paths now contain the new baseline logo and emblem for site compatibility. Previous images are saved in `assets/branding-candidates/parakeet-legacy-v2/`. Historical artwork and future seasonal packs should remain separately labeled.
